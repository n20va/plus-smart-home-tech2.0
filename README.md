# Smart Home Technologies

Многомодульный Java-проект для обработки телеметрии устройств умного дома и взаимодействия между сервисами.

## О проекте

Проект разработан в рамках расширенного курса Java-разработки Яндекса.

Система построена как набор сервисов, которые принимают и обрабатывают события устройств умного дома, передают данные между модулями и взаимодействуют через API и брокер сообщений.

В ходе работы над проектом я реализовывала и дорабатывала backend-логику, связанную с обработкой телеметрии, сериализацией данных и взаимодействием сервисов.

## Основные модули

### Telemetry

Модуль отвечает за работу с телеметрией устройств умного дома.

В его состав входят:

- `collector` - приём событий от устройств и Hub Router;
- `aggregator` - агрегация телеметрических данных;
- `analyzer` - обработка и анализ событий;
- `serialization` - схемы сериализации и общие модели данных.

### Commerce

Модуль содержит сервисы, связанные с коммерческой частью системы:

- `shopping-store` - работа с товарами;
- `shopping-cart` - управление корзиной;
- `warehouse` - складская логика;
- `interaction-api` - контракты взаимодействия между сервисами.

### Infrastructure

Содержит инфраструктурные компоненты и настройки, необходимые для взаимодействия сервисов.

### Hub Router

Компонент, через который в систему поступают события от устройств умного дома.

## Поток обработки данных

События от устройств поступают через Hub Router в сервис Collector. Collector принимает данные, преобразует их в формат Avro и отправляет сообщения в Apache Kafka.

Далее события могут использоваться другими сервисами для агрегации, анализа и дальнейшей обработки.

Такое разделение позволяет отделить приём данных от их последующей обработки и организовать асинхронное взаимодействие между компонентами системы.

## Запуск

Для запуска инфраструктуры используется Docker Compose.

```bash
docker compose up -d
```

После запуска инфраструктуры отдельные сервисы можно запускать как Spring Boot-приложения.

Для сборки проекта используется Maven:

```bash
mvn clean install
```
