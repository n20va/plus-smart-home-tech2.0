# Smart Home Technologies

Многомодульный Java-проект для обработки телеметрии устройств умного дома и взаимодействия между сервисами.

## О проекте

Проект разработан в рамках расширенного курса Java-разработки Яндекса.

Система построена как набор сервисов, которые принимают и обрабатывают события устройств умного дома, передают данные между модулями и взаимодействуют через API и брокер сообщений.

В ходе работы над проектом я реализовывала и дорабатывала backend-логику, связанную с обработкой телеметрии, сериализацией данных и взаимодействием сервисов.

## Основные модули

### Telemetry
- `collector` — приём событий от устройств и Hub Router;
- `aggregator` — агрегация телеметрических данных;
- `analyzer` — обработка и анализ событий;
- `serialization` — схемы сериализации и общие модели данных.

### Commerce
- `shopping-store` — работа с товарами;
- `shopping-cart` — управление корзиной;
- `warehouse` — складская логика;
- `interaction-api` — контракты взаимодействия между сервисами.

### Infrastructure
Содержит инфраструктурные компоненты и настройки для взаимодействия сервисов.

### Hub Router
Источник событий от устройств умного дома.
